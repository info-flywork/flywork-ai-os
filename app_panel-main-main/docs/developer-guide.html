Hızlı Başlangıç

  1. .env.example dosyasını .env olarak kopyalayın.
  2. npm install ile bağımlılıkları kurun.
  3. Veritabanını oluşturun ve migration dosyalarını çalıştırın.
  4. npm run seed ile super admin hesabını oluşturun.
  5. npm run seed:apps ile örnek uygulamaları ekleyin.
  6. npm run dev ile sunucuyu başlatın.

Not: Geliştirme sırasında özellikle API key ve RevenueCat değişkenlerinin doğru tanımlandığını kontrol edin.

Mimari Özeti

App Panel, uygulama bazlı harici backend API'lerini proxy ederek panel ekranlarına veri sağlar. Her uygulama için ayrı bir panel_slug, api_base_url ve gerekirse panel_api_key kullanılır.

  • Backend: Node.js + Express tabanlı route yapısı
  • UI: Public HTML/CSS/JS sayfaları (uygulama bazlı panel dosyaları)
  • Auth: Cookie tabanlı panel oturumu
  • Analitik: Uygulama backend + RevenueCat kaynaklı metrikler

Temel Akış

1) Kimlik Doğrulama

Kullanıcı panelde login olur, sunucu cookie bazlı oturum yönetir.

2) Uygulama Seçimi

Panel ekranında uygulama seçilir ve ilgili uygulama route'una gidilir.

3) Proxy ve Veri Çekimi

Sunucu, seçilen uygulamanın dış API'sine istek atar ve kanonik yapıya dönüştürerek UI'a iletir.

4) Yönetim İşlemleri

Kullanıcı düzenleme, metrik görüntüleme ve uygulamaya özel modül işlemleri panelden yapılır.

Yeni Uygulama Entegrasyonu

  • Uygulama için apps/{slug}/PANEL_API.md dokümanını oluşturun.
  • Gerekli uçları (/panel/health, /panel/analyse, /panel/users) hazır edin.
  • App Panel tarafında uygulama kaydını seedApps ve applications tablosu ile eşleştirin.
  • UI için gerekli ise src/public/apps-{slug}.html ve src/public/js/{slug}-panel.js dosyalarını ekleyin.
  • RevenueCat kullanılıyorsa {SLUG}_REVENUECAT_PROJECT_ID değerini tanımlayın.

Sorun Giderme

  • 403 veya 401: Uygulama bazlı API key eşleşmesini kontrol edin.
  • Eksik metrik: Harici uygulama API'sinde analyse dönüşünü doğrulayın.
  • Boş kullanıcı listesi: Pagination ve search parametrelerini kontrol edin.
  • RevenueCat verisi yok: Proje ID ve genel API key yapılandırmasını kontrol edin.
